# 読書・動画記録アプリ（PWA）

読んだ本と、オンラインで観た動画の感想を記録する、個人的なWebアプリです。
記録は端末の中（ブラウザのlocalStorage）に保存されます。

## できること
- 【本】ISBNバーコードをカメラで読み取り（手入力も可）
- 【本】ISBNからタイトル・著者・表紙画像を自動取得（openBD / Google Books）
- 【動画】サービス（YouTube / Netflix / Prime Video / Disney+ / その他）とURLを記録
- 【動画】YouTubeのURLからはサムネイル画像を自動表示。その他は画像URLを任意で入力可
- 読んだ日・観た日・評価（★）・感想を記録、一覧表示、種類フィルター、検索
- 記録の書き出し／読み込み（JSONバックアップ）
- 以前のバージョンで保存した本の記録は、そのまま「本」として表示されます

## VS Codeで開いて試す（Windows）
1. このフォルダをVS Codeで開く（ファイル → フォルダーを開く）
2. 拡張機能「Live Server」を入れる
3. `index.html` を右クリック →「Open with Live Server」
4. ブラウザで開けば動作確認できます（バーコード読み取りはPCのカメラでも試せます）

## iPhoneのホーム画面に置く
カメラとホーム画面追加には、HTTPSで公開されたURLが必要です。
例：GitHub Pages（無料）にこのフォルダを置く → SafariでURLを開く → 共有ボタン →「ホーム画面に追加」。

※ 公開の手順（アカウント作成・アップロード）は、実行前にむむたんに相談してね。

## 注意
- 記録は「ホーム画面に追加したそのアプリ」の中に保存されます。ブラウザのデータを消すと記録も消えるので、ときどき「記録を書き出す」でバックアップしてね。
- 表紙画像は外部サイトのURLを表示しているだけなので、オフラインでは表示されないことがあります。
